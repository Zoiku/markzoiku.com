# Mark Zoiku's Portfolio

A minimal static portfolio for Mark Zoiku, with a biography, links to public projects, contact links, and an archived portfolio link.

## View locally

Clone the repository and open `index.html` in a browser, or serve the directory with your editor's static web server. No package installation, build step, database, or environment variables are required.

## Files

- `index.html`: page content, project/contact links, and search/social metadata.
- `style.css`: typography and layout.

## Updating the site

Edit content and destinations in `index.html`, and update `style.css` for visual changes. Check the biography and project links for currency before publishing. The canonical and Open Graph URLs are set in the HTML.

Deploy the files together to a static host with `index.html` as the entry page.

## Checks

There is no automated test suite. Check the page at desktop and mobile widths, keyboard navigation, and every project, archive, email, and telephone link.
